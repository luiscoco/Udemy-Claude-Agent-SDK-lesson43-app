Configure and run the app.

Install the SDK, configure your key and run the classroom comparisons.

01

Prerequisites

Use Node.js 24+, model API access and available credit. Windows may require Git Bash; the test-runner executes one real Node command through Bash. Model comparison requires Haiku access. No GitHub token or remote service is required.

node --version
npm --version
02

Install and configure .env

Install pinned dependencies. Preserve an existing .env and enter your API key privately. The model key remains on the server and in the SDK subprocess environment.

cd .\agent-sdk\lesson43-subagents
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start and navigate

Keep the terminal open and use all five navigation buttons. All scenarios finish automatically and display native delegation evidence.

npm start
# http://127.0.0.1:3143
04

Run specialists and a team

Reviewer reads the toy module. Tests runs the actual assertion suite, including its intentional failure. Team requests both specialists in one turn and waits for reports. Inspect start/stop times; concurrency is observed rather than assumed.

npm run sample:env -- reviewer
npm run sample:env -- tests
npm run sample:env -- team
05

Compare isolation and explicit briefing

Isolation withholds the parent-only classroom label from the child task. Briefing explicitly supplies BRIEF-43. Readonly verifies the reviewer’s declared tools and actual child calls while file hashes remain unchanged.

npm run sample:env -- isolation
npm run sample:env -- briefing
npm run sample:env -- readonly
06

Compare models and creation paths

Model repeats the reviewer task with inherited and Haiku child models. Inspect observed IDs and native result estimates; these are not a controlled benchmark. Filesystem loads a real project agent definition; Builtin delegates to general-purpose.

npm run sample:env -- model
npm run sample:env -- filesystem
npm run sample:env -- builtin
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3143
# Windows only, if needed:
# CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. All experiments finish automatically. Inspect an Agent tool-use ID without sending another model prompt. Consume the entire query stream: asynchronous child completions can produce multiple native parent result frames. Change PORT if 3143 is occupied.
